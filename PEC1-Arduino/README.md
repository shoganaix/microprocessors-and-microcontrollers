# PEC1 — Arduino (C++)

Required assignment for *Microprocessors and Microcontrollers* (UNED). Five systems
designed and simulated as **Tinkercad** circuits, each with its own report inside the
assignment document.

## Projects (`circuits/`)

| Circuit | Description |
|---|---|
| `Keypad4x4_Tinker.brd` | 4×4 keypad access control system (valid code check) |
| `LED-RGB_Tinker.brd` | RGB LED control pattern |
| `TrafficLights_Tinker.brd` | LED traffic light sequence |
| `Alarm_Tinker.brd` | PIR motion detection alarm, disarmed via keypad |
| `Gas_Tinker.brd` | Gas detection with multi-level alarm (warning / critical) |

## Concepts covered

- Digital and analog I/O
- Keypad matrix scanning
- Interrupt-based alarm stop
- Multi-level alarm logic
- Circuit design and simulation in Tinkercad
