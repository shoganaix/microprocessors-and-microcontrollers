# 05 — GL5528 Light Sensor + Servo

Rotates a servo while reading the **GL5528 light sensor**; when the reading matches the
target value the servo stops, having "found the light".

- **Sensor:** GL5528 (light-dependent resistor) + servo
- **Key ideas:** analog read, servo control, threshold/target matching
