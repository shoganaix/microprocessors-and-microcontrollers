# 04 — TTC03 Thermistor vs DHT22

Compares temperature readings from a **TTC03 thermistor** (analog) and a **DHT22**
(digital) sensor, displayed on the I²C LCD and Serial Monitor.

The thermistor's analog reading is converted to temperature with the
**Steinhart–Hart equation**.

- **Sensor:** TTC03 thermistor + DHT22
- **Key ideas:** analog conditioning, Steinhart–Hart, dual-sensor comparison
