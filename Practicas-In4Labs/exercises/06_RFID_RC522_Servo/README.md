# 06 — RFID RC522 + Servo

Moves a servo to position an **RFID tag** near the reader, reads the tag **UID**, and
displays it on the I²C LCD and Serial Monitor.

- **Sensor:** RC522 RFID reader (SPI) + servo
- **Key ideas:** RFID card reading, UID extraction, actuator coordination
