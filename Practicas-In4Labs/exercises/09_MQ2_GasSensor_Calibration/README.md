# 09 — MQ2 Gas Sensor Calibration

Simulates the **calibration process** of the MQ2 gas sensor: several analog readings are
taken in clean air, averaged, and stored as a reference baseline for later detection.

- **Sensor:** MQ2 gas sensor (analog)
- **Key ideas:** signal averaging, baseline calibration, analog conditioning
